# Senior Citizen ID Registration System

## Overview
A full-stack web-based Senior Citizen ID Registration System developed for the Office of the Senior Citizens Affairs (OSCA).

## Features
- Online senior citizen registration
- Multi-step registration form
- Secure document upload
- PostgreSQL database
- Supabase Storage integration
- Express.js REST API
- Application status tracking

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database & Storage
- PostgreSQL (Supabase)
- Supabase Storage

## Installation

1. Clone the repository.
2. Install backend dependencies:

```bash
cd backend
npm install
```

3. Create a `.env` file using `.env.example`.

4. Start the server:

```bash
npm run dev
```
