# Senior Citizen ID Registration System

## Overview
A web-based Senior Citizen ID Registration System developed for the Office of the Senior Citizens Affairs (OSCA).

## Features
- Multi-step registration form
- File upload
- Supabase Storage integration
- PostgreSQL database
- Application status tracking
- Backend API using Express.js

## Technologies
- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- PostgreSQL
- Supabase
